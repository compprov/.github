# Support

## Getting Help

- **Questions & discussion:** Use [GitHub Discussions](https://github.com/compprov/compprov-core/discussions)
- **Bug reports:** Open a [GitHub Issue](https://github.com/compprov/compprov-core/issues) with the `bug` label
- **Feature requests:** Open a [GitHub Issue](https://github.com/compprov/compprov-core/issues) with the `enhancement` label

## Before Asking

Please search existing issues and discussions before opening a new one.

## Response Time

This is an open-source project maintained in spare time. We aim to respond to issues within a week.
