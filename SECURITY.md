# Security Policy

## Supported Versions

As compprov is currently in early development, only the latest version on `main` receives security fixes.

| Version | Supported |
|---|---|
| main (latest) | Yes |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities by emailing: **minas.abramyan@gmail.com**

Include in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

You will receive an acknowledgment within 48 hours. We aim to release a fix within 14 days
of a confirmed vulnerability, depending on severity.
